পড়ার সময় ট্র্যাক করার ফ্রি অ্যান্ড্রয়েড অ্যাপ

⬇️ StudyLog APK ডাউনলোড করুন

অ্যান্ড্রয়েড ফোনের জন্য · সম্পূর্ণ ফ্রি

কী কী আছে

  • নোটিফিকেশন স্টপওয়াচ, অ্যাপ বন্ধ থাকলেও সময় চলে
  • বিষয়ভিত্তিক পড়ার হিসাব
  • দৈনিক, সাপ্তাহিক ও মাসিক গ্রাফ
  • হোম স্ক্রিনে ৪টা উইজেট
  • ডাটা ব্যাকআপ আর ডার্ক/লাইট থিম

ইনস্টল করার নিয়ম

  1. ওপরের বাটনে ট্যাপ করে APK ডাউনলোড করুন
  2. ডাউনলোড হওয়া ফাইলটা খুলুন
  3. "অচেনা অ্যাপ ইনস্টল" এর অনুমতি চাইলে Allow দিন
  4. Install চাপুন

অ্যাপটা Play Store-এর বাইরে থেকে আসে, তাই ইনস্টলের সময় সতর্কতা আসতে পারে। এটা স্বাভাবিক।
